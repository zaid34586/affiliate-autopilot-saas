# FTC Affiliate Disclosure Rules for Creators (2026 Guide + Templates)

Disclosure is not optional, and it is not a vibe — it's a rule with specific placement and wording requirements. The good news: getting it right takes five minutes once, and it *increases* trust instead of reducing it.

## What the FTC actually requires

The Federal Trade Commission's Endorsement Guides require three things from affiliate creators:

1. **Clear and conspicuous disclosure** of material connections — any time you earn a commission, discount, free product, or payment for a mention.
2. **No buried disclosures.** "Link in bio *may* contain affiliate links" behind a "more" truncation does not count.
3. **Truthful claims.** If you say the product did something, it has to be true — disclosures don't rescue fabricated results.

Material connections include: affiliate commissions, sponsorships, free products, payment, employment, or a family/business relationship with the brand.

## Where disclosures must appear

| Surface | Requirement |
|---|---|
| Reel/video | Spoken **and** on-screen text in the first few seconds — before any affiliate link appears |
| Caption | First line, before the "more" fold |
| Bio | Permanent line if your bio contains affiliate links |
| Story | Text sticker on the frame with the link |
| DM | A line before you send an affiliate link |
| Blog | Above the fold, before the first link |

The test the FTC applies: **would a reasonable person see it?** If you have to tap, scroll, or squint — it fails.

## Wording that counts (and wording that doesn't)

**Counts:**

- "Paid partnership with [Brand]"
- "I earn a commission if you buy through my links"
- "Ad" or "#ad" — but only if it's unmissable
- "Affiliate link" next to the actual link

**Does not count:**

- "#sp", "#collab", "#ambassador" alone (ambiguous)
- "Thanks [Brand]!" (doesn't reveal payment)
- A disclosure in paragraph 8 of a caption
- Only in a hashtag block of 30 tags
- Only on a link-tree page

## Copy-paste templates

### Reel on-screen text (first 3 seconds)

> Paid partnership · I earn a commission on links below

### Reel spoken line (natural, one second)

> "This one's an affiliate link — I earn a commission if you grab it."

### Instagram caption, first line

> **Ad · affiliate links below — I earn a commission if you buy.**

### Bio line

> Some links are affiliate links — I may earn a commission.

### DM before a link

> Heads up: this is an affiliate link — I earn a commission if you purchase.

### Blog, above the first link

> **Disclosure:** This post contains affiliate links. If you purchase through them, I may earn a commission at no extra cost to you.

## The trust argument (why disclosure helps)

Creators worry disclosure kills conversions. Measured evidence points the other way:

- Disclosure pre-qualifies buyers. People who click *after* knowing it's an affiliate link are higher-intent — fewer refunds, fewer chargebacks.
- It signals confidence. Hedging reads as shame; plain disclosure reads as professionalism.
- It protects the account. FTC actions against creators are public, and platforms reduce distribution for undisclosed promotion when reported.

## A 5-minute compliance audit

Run this once on your account:

1. Bio contains an affiliate line? ✓
2. Last 10 promotional captions disclose in the first line? ✓
3. Last 10 promotional Reels have on-screen + spoken disclosure? ✓
4. DM template includes the disclosure line? ✓
5. Any income claims you can't document? → Fix or delete them today.

## The bottom line

Disclose early, disclose plainly, disclose every time. One line, first three seconds, every post. It's the cheapest compliance system you'll ever run — and it compounds into audience trust, which is the real asset behind every affiliate dollar.
